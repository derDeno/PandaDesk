Move desk up, down, or stop
POST/api/v1/commands/move

Request · application/json

{
  "request_id": "unique-id",
  "direction": "up",
  "expires_ms": 1000
 }

Response · 202 Accepted

{
  "accepted": true
 }

direction is up, down, or stop. Up/down run for expires_ms (1–5000 ms) and then stop automatically. Stop takes priority over queued API moves.

Move desk to a target height
POST/api/v1/commands/height

Request · application/json

{
  "request_id": "unique-id",
  "height_cm": 72.5
 }

Response · 202 Accepted

{
  "accepted": true
 }

height_cm must have one decimal and be within the saved limits. Out-of-range requests return 400 with height_out_of_range. Target-height control is unavailable for Loctek/FlexiSpot and JCHT35K72C.
