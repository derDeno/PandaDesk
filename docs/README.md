# PandaDesk documentation

[PandaDesk overview](../README.md)

Start with [setup](SETUP.md) if this is your first PandaDesk installation.

| Guide | What you will find |
| --- | --- |
| [Setup](SETUP.md) | Wiring basics, first boot, Wi-Fi, desk configuration, and connection troubleshooting. |
| [Web UI](WEBUI.md) | Movement, target heights, presets, child lock, logs, LED status, updates, and reset. |
| [Stream Deck plugin](STREAMDECK.md) | Elgato Marketplace installation, board connection, actions, and troubleshooting. Marketplace link to be added. |
| [HTTP API](API.md) | Request/response examples for state, capabilities, diagnostics, logs, and desk commands. |
| [Home Assistant / MQTT](INTEGRATIONS.md) | Broker setup, discovery, and custom local integrations. |
| [Hardware and compatibility](HARDWARE.md) | Interface targets, power, voltage limits, and wiring. |
| [Building and flashing](BUILDING.md) | PlatformIO builds, USB installation, flash layout, migration, and protocol captures. |
| [Firmware architecture](ARCHITECTURE.md) | Desk profiles, GPIO mapping, UART forwarding, wake handling, child lock, presets, scheduling, and checks. |

Commands in the technical guides run from the firmware root (the directory
containing `platformio.ini`), unless a guide says otherwise.
